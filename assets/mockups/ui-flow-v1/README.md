# COPIE UI Flow — White Cyberism

ชุดภาพต้นแบบหน้าจอเดสก์ท็อป 16:9 สำหรับส่งต่อให้ทีมออกแบบและพัฒนา ใช้ภาพหน้าหลัก `copie-white-cyberism-profile-history-v6.png` เป็นทิศทางหลัก

อ่านคำอธิบายส่วนประกอบและพฤติกรรมของแต่ละภาพได้ที่ [SCREEN_GUIDE.md](SCREEN_GUIDE.md)

## ภาษาภาพร่วม

- พื้นขาวเป็นหลัก เส้นกริดฟ้าจาง สีดำสำหรับหัวข้อ และน้ำเงินสำหรับสถานะหรือปุ่มหลัก
- COPIE อยู่กลางจอเมื่อสนทนา และย่อไปด้านขวาเมื่อเนื้อหาต้องใช้พื้นที่อ่าน
- คำตอบ AI แสดงเป็นส่วนหนึ่งของหน้า ไม่ใช้ฟองแชตแบบทั่วไป
- โลโก้ COPIE อยู่ซ้ายบน โปรไฟล์อยู่ขวาบน และ History เปิดจากซ้ายล่างหลังเข้าสู่ระบบ
- ฟอนต์แนวเทคนิคใช้กับหัวข้อและป้ายสถานะ ส่วนเนื้อหาภาษาไทยต้องอ่านได้ง่าย

## การเปลี่ยนสถานะหลัก

`Login → Onboarding (ผู้ใช้ใหม่) → Composing → AI answer → Reading mode / History`

`AI answer → Assessment intro → Assessment question (1–12) → Skill radar`

ภาพเหล่านี้เป็นแนวทางหน้าตา UI ยังไม่ใช่หน้าที่กดใช้งานได้จริง ข้อความรายวิชา คะแนน และผลประเมินในภาพเป็นตัวอย่างสำหรับออกแบบ ข้อมูลจริงต้องมาจากระบบและแหล่งอ้างอิงของโปรเจกต์
