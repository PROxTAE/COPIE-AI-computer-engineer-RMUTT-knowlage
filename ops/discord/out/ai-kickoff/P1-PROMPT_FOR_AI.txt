ฉันรับผิดชอบ P1 ของโปรเจกต์ COPIE ต้องทำงานตามแผนให้มากที่สุดและ commit โค้ดภายในวันอาทิตย์ที่ 27 ก.ย. 2026 (เวลาไทย) งานนี้ต้องเดินต่อเนื่องจนจบส่วนที่รับผิดชอบ ไม่หยุดหลังทำ PR แรก

ให้เปิดอ่านไฟล์ใน ZIP ที่แนบทั้งหมดโดยเริ่มจาก START_HERE.md, เอกสาร 00 กลาง, AI_EXECUTION_INSTRUCTIONS.md, 01_FRONTEND_CORE_MASCOT.md, contract ทั้งสองฝั่ง และไฟล์ประกอบเฉพาะงาน (ภาพเป็นแบบหน้าตา ไม่ใช่ข้อมูลจริง) แล้วตรวจโค้ดใน repository ปัจจุบันก่อนแก้ อย่าทำงานซ้ำสิ่งที่มีอยู่แล้ว

เริ่มจาก PR แรก (`core/white-cyberism-theme`): ตรวจงานธีมที่ทำอยู่ แล้วทำให้ asset kit, ฟอนต์, HeroUI theme, CopieMascot และหน้า preview ใช้งานได้ตามแผน; ส่ง screenshot เทียบ mockup
สิ่งที่ต้องส่งต่อให้ทีม: ส่ง tokens/ui และมาสคอตให้ P2/P6; เตรียมจุดต่อ chat API ของ P3 กับ Renderer ของ P6

ทำงานตาม Phase ของแผน P1 ต่อเนื่องไปจนถึง Definition of Done โดยแยกเป็น PR เล็กตาม Branch / PR breakdown ในแผน อย่ารวมทุกอย่างใน PR เดียว หลังจบแต่ละ slice ให้ตรวจและสรุปผลเพื่อให้ฉัน commit/push/เปิด PR แล้วจึงไป slice ถัดไป ถ้างานใดต้องรอเพื่อน ให้ทำ stub/fixture ตาม contract เฉพาะระหว่างพัฒนา แจ้งว่ารอฟังก์ชันหรือข้อมูลอะไร แล้วทำงานส่วนอื่นต่อทันที

แก้เฉพาะไฟล์ที่แผนระบุว่าเป็น Ownership ของ P1 ถ้าต้องแก้ contract หรือไฟล์เจ้าของอื่น ให้เสนอผลกระทบและหยุดก่อนแก้ ห้ามสร้าง field/endpoint เอง ข้อมูลภาค รายวิชา หน่วยกิต และคะแนนต้องมีแหล่งจริงหรือสูตรตรวจได้; ใช้ mock/stub เฉพาะงานพัฒนาและ tests ห้ามปล่อย mock ไว้ใน flow demo จริง

ก่อนเริ่ม ให้สรุปสั้น ๆ ว่า (1) เข้าใจ scope/contract อย่างไร (2) ไฟล์ใดมีอยู่แล้วหรือยังขาด (3) จะทำไฟล์ใดใน PR นี้ แล้วลงมือทำและรันการตรวจ: cd frontend แล้วรัน npm run lint และ npm run build; ถ่ายภาพหน้า preview/chat

หลังแต่ละ slice รายงานไฟล์ที่แก้ ผลตรวจ หลักฐาน ข้อที่ยังรอคนอื่น และร่างข้อความ PR ตาม PR_TEMPLATE.md (PR แรกตัวอย่างชื่อ `style(core): add white cyberism theme`, base `develop`, reviewer P6) พร้อมแนะนำ slice ถัดไปทันที อย่า commit, push, เปิด PR หรือ merge แทนฉัน; ฉันจะตรวจ diff และทำ Git เองภายในสุดสัปดาห์ ห้ามใส่ AI attribution, secret หรือไฟล์ตั้งค่าของ AI ใน repo
